# HydroAgent-XW：新吴区水务多源数据智能分析 Agent

HydroAgent-XW 是一个面向无锡市新吴区水务治理场景的多源数据智能分析 Agent 项目。项目基于 AutoGIS 的后端和空间分析框架进行二次开发，接入水环境整治报告、实时水务数据、泵闸位置、管网资料和现场照片等多源数据，目标是构建一个可解释、可扩展、可评测的城市水务智能分析系统。

## 当前 MVP 能力

- 解析新吴区水环境整治报告，将 docx 转换为结构化 `reports.jsonl`
- 解析新吴区实时数据 Excel，将 xlsx 转换为 CSV
- 新增 `/api/hydro/query` 查询接口
- 支持报告类问题检索
- 支持实时数据表结构识别
- 支持字段字典查询，例如 `device_value`、`device_status`
- 支持根据字段语义推断可做的水务分析方向
- 返回 `answer`、`sources`、`debug`，便于解释和调试
